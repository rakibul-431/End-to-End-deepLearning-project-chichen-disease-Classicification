# End-to-End-deepLearning-project-chichen-disease-Classicification
The project will be completed by ANN CNN and Tensorflow Framwork that will help to know is there any disease in chichen.
### Step 01 Creat a conda environment after opening the repository

```bash
conda create -n chickenConda python=3.8 -y
```

```bash
conda activate chickenConda
```

### Step 02 Install requirments file
```bash
pip install -r requirements.txt
```
